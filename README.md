# moreInfoDS – KWin Window Switcher Layout

Modified version of **Modern Informative** that shows both **D**esktop and **S**creen information on the right side.

When filtering by screen is disabled (or across multiple monitors), it displays the exact screen name (e.g. `HDMI-A-1`, `DP-1`) where each application resides.

Based on Modern Informative by Mélanie Chauvel (ariasuni) and the code of [Compact](https://invent.kde.org/plasma/kdeplasma-addons/-/blob/Plasma/6.0/windowswitchers/compact/contents/ui/main.qml).
